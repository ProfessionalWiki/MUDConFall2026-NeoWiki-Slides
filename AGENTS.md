# AGENTS.md

These slides present NeoWiki. Before changing them

* Read NeoWiki's [AGENTS.md](https://github.com/ProfessionalWiki/NeoWiki/blob/master/AGENTS.md)
* Use [NeoWiki's Ubiquitous Language](https://github.com/ProfessionalWiki/NeoWiki/blob/master/docs/glossary.md). Avoid
  using other terms to refer to NeoWiki's concepts. Example: do not use "record" to refer to a Subject. Terms do not
  have to be capitalized like they are in the glossary.
